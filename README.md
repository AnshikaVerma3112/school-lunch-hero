#Welcome to our School lunch Sustainability Auditor
School Lunch Sustainability Auditor
A modern, responsive web application designed for students to track, audit, and improve the environmental impact of their daily school meals. Built as a college project to bridge the gap between daily habits and environmental consciousness.

🚀 Features
7-Day Sustainability Planner: Full weekly coverage (Monday–Sunday) to track meal choices and eco-impact.

Quick-Add Sidebar: One-click entry for common sustainable items (e.g., "Zero Waste," "Plant-based," "Reusable Container").

Data Persistence: Integrated with localStorage so your audit data stays saved in your browser even after a refresh.

Aesthetic Dashboard: A clean, student-friendly UI built with accessible shadcn/ui components.

Responsive Design: Fully functional on desktop and mobile, ensuring you can audit your lunch right in the cafeteria.

🛠️ Tech Stack
Framework: React 18 with Vite

Language: TypeScript (for type-safe, reliable code)

Styling: Tailwind CSS & Lucide React (Icons)

UI Components: shadcn/ui (Radix UI primitives)

State Management: React Hooks & LocalStorage API

Routing: React Router DOM v6

📦 Installation & Setup
To run this project locally, follow these steps:

Clone the repository:

Bash
git clone [your-repository-link]
Navigate to the folder:

Bash
cd school-lunch-sustainability
Install dependencies:

Bash
npm install
Start the development server:

Bash
npm run dev
Build for production:

Bash
npm run build
